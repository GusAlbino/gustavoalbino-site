Elos Saber

elossaber.com.br

Website for Elos Saber, the training, consulting and development practice of Prof. Dr. Carolina Galdino, a doctor in International Relations. Four programmes, one brand voice, and a site her own team can keep up.

About the site

Four programmes, one way in.

The home page opens with “Somos ponte” and leads to a WhatsApp conversation, where sales happen. Dark or light theme, chosen by the visitor.

How it was made

The workflow, short version.

Conversation. Understanding Carolina, her audience and what the site has to sell.

Brand and system. Vector redraw of the logo, a 36-page brand manual and colour and type tokens.

Layout. Three page models shown to her. Carolina chose the Editorial one.

Code. Pages in HTML and CSS, generated from a single set of data and components.

Review. Two rounds of her corrections, with automated checks and manual testing of the controls.

Publishing. Code on GitHub and the site live on Cloudflare, on her own domain.

The switch

From Lovable and WordPress to code of its own.

The elossaber.com.br address was running an old WordPress site on shared hosting. In parallel there was a version built in Lovable, which produced screens but tied the project to the platform and made precise changes hard.

I rebuilt the site in code. The pages come out of a static generator, with no database and no admin panel to maintain. Every text and every colour lives in a file, so the result is light, fast and has no plugin to break.

The code lives in a GitHub repository, which works as history and backup. Publishing happens on Cloudflare: the site runs on Workers, the domain's DNS is there too, and the domain's email is forwarded through Email Routing.

Lovable and WordPress stopped being the source of the site. The repository and the generator took over.

Design system

Purple, gold and a serif accent.

Four fixed colours, purple as the main one and gold as the accent, the colour of the logo. Text is set in Host Grotesk and, in one word per headline, Instrument Serif italic.

The brand became a combined mark: logo, signature and symbol. I redrew the rings as vectors, with continuous lines that thin out where they pass behind the other ring.
